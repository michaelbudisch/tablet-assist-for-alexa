# TAFA Home Dashboard · Änderungen

## 0.2.1 — Release Candidate (24.11.2026)

- Bündelung von Home-Assistant-Statusmeldungen in 250-ms-Fenstern.
- Anstehende Updates beim Verlassen der Karte sicher abbrechen.
- Drei neue Regressionstests für die Update-Bündelung und das Aufräumen; insgesamt 38 synthetische Prüfungen.
- Optionale Module für Laufzeit-/FPS-Messungen, Sprachreaktionszeiten und Echo-Relay-Status bereitgestellt.
- Keine private Konfiguration veröffentlicht.

**Status:** Release Candidate auf separatem Branch. Reale Tablet-/Mikrofon-/Bluetooth-Messungen und Prüfung einer Neuinstallation stehen noch aus. Das portable Dashboard ersetzt das private Kiosk-Dashboard nicht vollständig.

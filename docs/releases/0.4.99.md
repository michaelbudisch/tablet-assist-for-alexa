# TAFA 0.4.99 — source integration checklist

This file documents the **GitHub main-branch source**. A tag/release, Home Assistant Marketplace/HACS package update, or signed Android APK is **not automatically published** by merging these commits.

## Changes merged

- Central per-device Ambient profile storage with revision conflict checks and scoped HA WebSocket access
- Dashboard editor to configure each tablet's calendar, proximity sensor, auto-open/close policy, display duration and sensor labels
- Ambient runtime reads the selected paired tablet's profile and voice status dynamically; updates are delivered without overwriting another device
- Limited Ring motion notice stream, allowed only for paired users with camera-read permission
- Ring popup previews show the configured last-recording camera instead of initiating a live view
- Ring camera-mapping editor for first-time setups
- Vision diagnostic cards display the last analyzed frames and inference information without triggering another analysis
- Ring recording timestamp discovery uses Ring's stable unique IDs, not another installation's sensor names
- Static frontend routes and cache-busting paths updated; documentation in German and English
- Existing HA automations, user-specific dashboard configs, stored profiles, credentials and app connections are **not** part of the public source

## Verification performed

- JavaScript syntax of all modified frontend modules checked
- Imports, Home Assistant static asset registrations and WS command registration cross-checked
- No known private household camera names, private network addresses or sensitive values copied into these newly synchronized components
- Existing private HA instance had previously verified both Ring recording camera mappings and successful Qwen structured 12-frame inference
- **Not yet verified on a fresh public TAFA installation**: full live UI navigation, browser/WebView rendering, end-to-end Ring motion popup and cross-tablet profile update after an actual release
- GitHub returned **no CI status checks** for the final source commit

## Smoke test before tagging a release

1. Install the 0.4.99 integration source into a disposable HA test environment; confirm no startup errors.
2. Open TAFA Dashboard → More → Settings and verify both the Ring camera-mapping editor and Ambient tablet settings.
3. Pair two tablets with distinct rooms, save different Ambient profiles and check changes remain isolated.
4. Trigger a permitted Ring motion notice, test normal and Ambient presentation, and verify no new livestream.
5. Run Ring Qwen inference on both cameras; confirm the vision diagnostic contact sheet and 60-minute expiry.
6. Confirm existing automations and users' HA source bindings remain unchanged after update.

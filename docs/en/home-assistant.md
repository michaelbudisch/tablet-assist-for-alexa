# Historical manual Jarvis installation

[Deutsch](../home-assistant.md) · [Current TAFA setup](setup-guide.md) · [TAFA App](app.md)

**Warning: this is not a fresh-install guide.** The former two-integration Jarvis setup, manual Lovelace card copies, custom helpers and token-based speech server APIs belong to older releases.

For **new installations**, use the unified TAFA App (CPU services and Control Center) or the [Marketplace-only alternative](marketplace.md). **Never manage the same integration through both routes.**

Before migrating an existing system, back up HA and inventory custom dashboards, helpers and automations. Migrate deliberately to the [TAFA Lokal](setup-guide.md) STT/conversation/TTS pipeline. Old `piper_api_token` entries and separately installing `jarvis_tablet_audio` are **not** fresh TAFA installation steps.

The previous full guide remains available as a [historical Jarvis reference](../archive/legacy-home-assistant.en.md) for migration only. Older commands may no longer apply to current Home Assistant versions.
